# Mud and Blood Co-Op Mod

Unofficial cooperative modification for Mud and Blood.

[Download the latest release](https://github.com/staltmedia/Mud-and-Blood-Co-Op-Mod/releases/latest). Choose **MudAndBlood-Coop-Update.zip** under Assets, extract the complete folder, start Steam, and double-click **Play Co-op.cmd**.

Each player needs the supported unmodified Steam game, version 0.5.3b. The launcher builds an isolated copy and checks this repository for future updates. Earlier launchers need a one-time download from this repository because the update address changed.

Gameplay remains experimental Alpha 2.3. Shared unit control, independent cameras and menus, separate commander profiles, and local settings are included. See the package README for limitations.

## Controls (2.3.4)

- **F6:** personal menu.
- **F7:** local settings and support bot options.
- **F8:** connection panel; click Host, Join, Disconnect or Hide banner.
- **F9:** original tactical view, independent for each player.
- **Esc:** original in-game menu or close the current panel.

F12 is available for Steam screenshots.

Patch code only. No original game executable, game assets, personal saves, or logs are distributed. Not affiliated with urb Games.
